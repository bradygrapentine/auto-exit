# Track: Extension

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Terminal/session name:** `kea-ext`
**Worktree path:** `worktrees/track-ext/`
**Branch naming:** `feat/ext/<slug>`
**PR labels:** `track:ext`, `area:extension`

This track owns all files under `code-and-docs-from-chatgpt/extension/`. No engine `src/` files, no TUI components, no MCP tool registrations except where an ext story adds a server endpoint that calls into shared modules — those endpoints live in `src/server.ts` and require a coordination PR with the shared track.

**Fan-out gate:** SP1.1–SP1.6 can start immediately (no engine prereqs). SP1.7 requires account-connect to be merged (already shipped per BACKLOG.md). SP1.8, SP2.3, SP3.3, SP4.3 require their respective shared/engine prereqs.

---

## Subagent dispatch policy

Default routing: **Sonnet implements, Opus session advises.**

1. Implementer subagents are dispatched as `general-purpose` with `model: "sonnet"`. Per superpowers:subagent-driven-development.
2. The Opus session running this terminal is the orchestrator: it dispatches Sonnet, reviews output between tasks, makes judgment calls.
3. Full Opus subagent takeover only when a blocker proves sticky: 2+ Sonnet attempts failed, hit an architectural wall, or wrong decision needs unwinding.
4. Codex adversarial review (`codex:codex-rescue`) is a mandatory gate before merge regardless of who implemented.

Heartbeat: any subagent running >30min appends timestamps every ~5min to `.claude/agent-status/<id>.log` per superpowers:subagent-heartbeat.

**Goal:** content script reads `window.location.pathname` + market header DOM; surfaces detected ticker with "use this" button; falls back to manual input.

**File-touch boundary:**

**Tasks:**
- [ ] Implement `ticker-detector.ts`: parse `window.location.pathname` + DOM market header
