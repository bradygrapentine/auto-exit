# Premium Feature Ideas

## Free/local MVP

- losing exit only
- one position at a time
- manual config
- dry-run preview

## Paid/pro

- polished extension UI
- saved presets
- winning-position smart exits
- ladder exits
- execution reports
- slippage/recovery estimate
- portfolio monitor
- expiry/liquidity alerts
- CSV export
- crash-safe resume

## Positioning

Do not market as an alpha/trading bot. Market as:

> Local-first execution assistant for prediction market exits.

The value is execution UX, safety guardrails, and slippage reduction in thin markets.
